\# Soumen Roy — Engineering Portfolio



Welcome to my engineering portfolio website. This project showcases my background, skills, projects, and professional work.



\*\*Live Website:\*\* https://soumenroy-engineering-portfolio.netlify.app/



\*\*GitHub Repository:\*\* https://github.com/soumenroyunofficial-tech/Soumen\_Roy-Engineering-Portfolio



\## Technologies Used



\- React

\- TypeScript

\- Vite

\- CSS

\- Netlify



\## Run Locally



\### Prerequisites



\- Node.js and npm

\- Git (optional)



\### Installation



Clone the repository and enter the project directory:



```bash

git clone https://github.com/soumenroyunofficial-tech/Soumen\_Roy-Engineering-Portfolio.git

cd Soumen\_Roy-Engineering-Portfolio

```



Install dependencies:



```bash

npm install

```



Start the development server:



```bash

npm run dev

```



\## Production Build



Build the project for production:



```bash

npm run build

```



The generated production files are placed in the `dist` directory.



\## Deployment



The website is hosted on Netlify and connected to GitHub. Pushing changes to the configured production branch can trigger an automatic deployment.



Typical Vite settings:



\- Build command: `npm run build`

\- Publish directory: `dist`

\- Production branch: `main`
